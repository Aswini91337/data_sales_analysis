# Sales Data Analysis Dashboard

A simple Sales Dashboard built using Python, Flask, Pandas and Chart.js.
It shows total sales, top products, and monthly sales trends from sales.csv data.

## Features
- Total Sales, Total Orders, Average Order Value
- Top 5 Selling Products
- Monthly Sales Trend Chart
- Clean Dashboard UI

## Tech Stack
- Python
- Flask
- Pandas
- HTML, CSS, JavaScript
- Chart.js

## Files
- app.py - Flask web app
- analysis.py - Data analysis using Pandas
- sales.csv - Sales dataset
- hello.py - Practice file

## How to Run
1. Install requirements:
   pip install flask pandas
2. Run the app:
   python app.py
3. Open browser:
   http://127.0.0.1:5000
